# Telegram bot

Минимальный каркас Telegram-бота на TypeScript и [grammY](https://grammy.dev/).

## Требования

- Node.js 22.6 или новее
- Telegram Bot API token

Node.js запускает TypeScript с удалением типов через `--experimental-strip-types`, поэтому отдельная сборка и TypeScript runtime-зависимость не нужны.

## Запуск

1. Установите зависимости: `npm install`.
2. Создайте `.env` на основе `.env.example`, задайте `API_TOKEN` и свой Telegram ID в `ADMIN_TELEGRAM_IDS`.
3. Запустите PostgreSQL: `docker compose up -d db`.
4. Запустите бота: `npm run dev`.

Укажите в `.env` `DATABASE_URL` для PostgreSQL, `ADMIN_TELEGRAM_IDS` со списком Telegram ID администраторов через запятую и оба способа перевода в `PAYMENT_METHODS` (пример заполнения — в `.env.example`). `ru_card` — перевод на карту российского банка, `fr_bank` — перевод по французским банковским реквизитам. Для каждого укажите реальные данные получателя, номер карты или IBAN и BIC/SWIFT. Не добавляйте реквизиты в Git. Оплата по ссылке не поддерживается. Если покупателю нужен другой способ, он может нажать «Написать администратору» прямо в сообщении об оплате. После перевода покупатель отправляет скриншот или фото чека; бот передаёт его администратору на проверку. Выбранный способ оплаты также виден администратору. Если `PAYMENT_METHODS` не заполнен, бот не предлагает оплату и направляет покупателя к администратору. Список ID является точным allowlist: при запуске бот активирует указанные ID и деактивирует отсутствующие в нём записи. Бот применяет `db/schema.sql` и проверяет соединение с БД. Для нового пользователя запись создаётся при `/start`; повторный запуск показывает приветствие для вернувшегося пользователя. Главное меню администратора дополнено пунктом панели с проверкой доступа при каждом обращении.

Главное меню показывает компактный список активных тарифов одним сообщением с кнопками выбора; в панели администратора список также собран в одном сообщении. При первой инициализации БД добавляются актуальные тарифы: один пост без закрепа — 10 €, один с закрепом — 15 €, четыре поста за месяц — 30 €, проверенный специалист на 1/3/6/12 месяцев — 50/135/250/480 €. Старые тарифы удаляются, если не связаны с заказами; тарифы из истории остаются скрытыми, чтобы не нарушать связи и сохранить историю заказов. Главное меню также запускает пошаговую анкету рекламодателя, раздел «Мои заявки», реферальную программу, «Задать вопрос» и «Настройки». Выдаётся персональная реферальная ссылка со статистикой (переходы, регистрации, заявки, оплаченные рекомендации). Сохраняются вопросы по выбранной теме. Незавершённые анкеты хранятся в БД и продолжаются после перезапуска. Вопросы отправляются активным администраторам из `admins`; для пересылки укажите их ID в `ADMIN_TELEGRAM_IDS`. Запрос на удаление данных из «Настроек» сохраняется как обращение, приходит администраторам отдельным сообщением и отображается в разделе панели «Удаление данных».

После анкеты пользователь выбирает тариф и задаёт дату для каждой публикации в одном редактируемом сообщении. Даты можно согласовать после оплаты. Затем пользователь проверяет сумму и подтверждает заказ; снимок дат сохраняется в заказе. Администратор подтверждает заказ, пользователь выбирает настроенный способ оплаты и сообщает об оплате. После проверки бот просит передать рекламные материалы; даты публикаций повторно в материалах не запрашиваются.

Панель администратора поддерживает добавление, редактирование и отключение тарифов. У тарифа отдельно задаются площадки, состав размещения, количество публикаций, срок размещения, срок запроса отзыва после публикации, дополнительные условия, цена и срок скидки. После публикации администратор может приложить ссылку; бот отправляет подтверждение рекламодателю и через заданный для тарифа срок спрашивает результат. Ответы сохраняются, запрос обсудить результат отправляется администраторам, а повторный заказ показывает действующие тарифы. В реферальном разделе администратор задаёт сумму и валюту бонуса, срок действия, допустимые тарифы и совмещение со скидкой; бонус начисляется пригласившему после первой подтверждённой оплаты и виден в статистике пользователя. При запросе исправлений рекламодатель получает свой пост целиком — текст, ссылку, дату, пожелания и медиа — вместе с комментарием администратора и кнопками выбора правок; удаление отдельных файлов доступно одним списком внутри пункта «Изменить медиа». Просмотр тарифов и заказов показывает снимок условий на момент заказа. Также доступны просмотр и фильтрация заявок, вопросы, подтверждение оплат, смена статуса и планирование публикации, личные сообщения рекламодателям, реферальные показатели и сводная статистика. Автоматические рекламные рассылки и проверка рекламных файлов пока не реализованы.

Локальная PostgreSQL запускается командой `docker compose up -d db`. Compose использует постоянный том `bot-seller-pgdata`, порт `127.0.0.1:55432` и учётные данные из локальной конфигурации.

`npm start` запускает тот же entry point для production-среды.

## Архитектура

```text
src/
  index.ts                 # запуск процесса и graceful shutdown
  config/
    env.ts                 # загрузка и проверка переменных окружения
  bot/
    create-bot.ts          # создание grammY Bot и регистрация команд
    handlers/
      start.ts             # обработчик /start
      help.ts              # обработчик /help
      menu.ts              # тарифы, анкета, реферальный раздел и вопросы
      admin.ts             # административная панель
  services/
    start-service.ts       # подготовка первого запуска и проверка администратора
    advertiser-service.ts  # анкета рекламодателя и диалог с вопросами
    admin-service.ts       # тарифы и действия панели администратора
  db/
    initialize.ts          # применение схемы PostgreSQL при запуске
    repositories/          # типизированный доступ к пользователям и данным рекламодателей
```

Командные обработчики размещаются в `src/bot/handlers`, бизнес-логика — в `src/services`, а SQL-запросы — в типизированных репозиториях `src/db/repositories`.

Секреты хранятся в `.env`, который не следует добавлять в Git. Для локальной настройки используйте `.env.example`.
